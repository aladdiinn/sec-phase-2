TYPOGRAPHY RULES:
• Page titles → font-family: Orbitron, font-size:13px, letter-spacing:2px, color:#fff
• Stat numbers → Orbitron, 22-28px, color: --cyan (or red/amber for critical/warning)
• Section labels, badges, meta text → Share Tech Mono, 9-10px, letter-spacing:2px, uppercase
• Body, descriptions, nav items → Rajdhani, 12-14px
• NEVER use system-ui, Inter, or Roboto anywhere

BACKGROUNDS:
• Page bg: #060f1e
• Sidebar bg: #0a1628, right border: 1px solid rgba(0,200,255,0.2)
• Cards/surfaces: #0a1628, border: 1px solid rgba(0,200,255,0.2), border-radius:8px
• Add top highlight line on each card: 1px gradient (transparent→cyan→transparent)
• Add subtle repeating scanline texture on page bg (CSS bg-image, 3% opacity)

SIDEBAR:
• Logo area: ShieldLock icon in cyan-bordered box + "SECUREPULSE" in Orbitron 8px
• Nav items: Mono font, 10px, letter-spacing:1px, uppercase, icons 13px
• Active item: bg rgba(0,200,255,0.1), left border 2px solid cyan, color cyan
• Hover: bg rgba(0,200,255,0.05), color rgba(0,200,255,0.7)
• Logout: color --red, hover underline

STAT CARDS (dashboard):
• Card bg #0a1628, border 1px solid rgba(0,200,255,0.2), radius 8px
• Top edge: 1px gradient line cyan
• Corner bracket accents (CSS ::before/::after, cyan 1.5px)

• Number: Orbitron 22px — cyan if normal, red if critical, amber if warning
• Label: Mono 9px, letter-spacing:2px, color rgba(200,232,248,0.5)
